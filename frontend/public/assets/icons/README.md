# Иконки интерфейса

Положите сюда собственные файлы иконок. Компонент `AssetSlot` ищет файл по ожидаемому имени и пробует расширения `.svg`, `.png`, `.webp`, `.jpg` и `.jpeg`. Например, для имени `hero-icon-1` подойдут `hero-icon-1.svg` или `hero-icon-1.png`. Иконки для первого экрана называются `hero-icon-1` … `hero-icon-5`, иконка поиска — `search`.
